# AFTERGLOW 0.9 — AI 陪伴原型（Windows）

本版本在 0.7 的基础上增加了「根据聊天整理剧情」功能。用户可在编辑剧情时让已配置的 AI 模型根据最近聊天生成标题、已发生内容和待续线索草稿，再检查并手动保存。

## Windows 快速启动
1. 安装 Python 3.11 或更新版本，安装时勾选 **Add Python to PATH**。
2. 双击 `启动_AFTERGLOW.bat`。首次运行会创建虚拟环境并安装依赖。
3. 在项目文件夹中复制 `.env.example` 并命名为 `.env`，填写你选择的模型服务商提供的 API Key、基础地址和模型 ID。
4. 浏览器访问 `http://127.0.0.1:8000`。不要直接双击 `index.html`，真实 AI 请求需要后端。

## 0.9 新增
- 新增 `/api/summarize-plot` 后端接口，可根据最近 30 条对话生成可编辑的剧情摘要草稿。
- 整理结果不会自动覆盖保存；用户需要检查并点击“保存剧情”，避免错误记忆被静默写入。
- 对不支持 JSON 输出模式的兼容接口增加了回退请求。

## 0.7 原有功能
- 每个角色独立保存剧情标题、已发生内容和下次待续线索。
- AI 请求会带上剧情线索，提示模型延续已记录的情节，不把未发生的内容说成事实。
- 数据导出包含剧情线索，便于备份。
- 修正后端读取关系阶段的处理逻辑。

## 当前限制
- 记忆和剧情线索保存在当前浏览器的 localStorage 中；清理浏览器数据可能丢失，暂不支持账号和跨设备同步。请定期导出备份。
- 记忆识别仍基于简单规则，保存前请检查和编辑。不要保存密码、证件号码或其他高敏感信息。
- 自动剧情整理依赖已配置的模型接口，输出可能有遗漏或误解；保存前请检查。它只处理最近聊天片段，不保证完整回忆所有历史。
- AI 聊天内容会发送到你配置的模型服务商。请先阅读其数据处理条款。
- 本项目不附带 API Key，也不保证模型服务永久免费。以服务商当前官方定价和免费额度为准。
- 未配置模型时，应用使用本地示例回复；这不是真实 AI 回复。

## API 配置
复制 `.env.example` 为 `.env`，填写 `AI_API_KEY`、`AI_BASE_URL` 和 `AI_MODEL`。`.env` 不要提交到公开代码仓库。


## 0.9 新增
- AI 记忆候选整理接口 `/api/suggest-memories`：仅生成候选，前端必须由用户确认后才保存。
- 记忆类型：偏好、个人信息、重要事件、约定、剧情。
- 聊天时按当前消息进行轻量相关性排序，最多选择 8 条记忆注入模型上下文，降低无关记忆干扰与 token 消耗。
- 记忆整理需要先配置可用的 OpenAI 兼容模型 API；未配置时不会伪装成自动 AI 整理。
